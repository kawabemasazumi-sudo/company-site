# スカイライン・テクノロジーズ 企業サイト

業務システムとSaaSの設計・開発・運用を一貫して手がけるソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。`index.html` 1ファイルで構成された静的なページで、ビルドやサーバーは不要です。

## ページ構成

| セクション | 内容 |
| --- | --- |
| お知らせ | リリース・会社情報・イベントの新着情報 |
| ヒーロー | キャッチコピーと、夜景のスカイラインのアニメーション（Canvas） |
| 事業内容 | 技術顧問・内製化支援／SaaSプロダクト開発／業務システム受託開発／クラウド基盤・運用 |
| 導入実績 | 配送計画システムの刷新、勤怠管理SaaSの立ち上げ、融資審査ワークフローの電子化 |
| 開発の進め方 | ヒアリングから運用・改善までの5ステップと目安期間 |
| 会社概要 | 代表メッセージと会社情報 |
| 採用 | エンジニア・デザイナーの募集案内 |
| お問い合わせ | 入力チェック付きのフォーム（デモのため送信はされません） |

## ブラウザで開く手順

### 方法1: ファイルを直接開く

1. エクスプローラーでこのフォルダ（`company-site`）を開きます。
2. `index.html` をダブルクリックします。既定のブラウザでページが表示されます。
   - 別のブラウザで開きたい場合は、`index.html` を右クリックし「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへドラッグ＆ドロップします。

### 方法2: コマンドから開く

PowerShell でこのフォルダに移動してから実行します。

```powershell
start index.html
```

### 補足

- フォントは Google Fonts から読み込むため、インターネットに接続していない環境では代替フォントで表示されます。
- OSでアニメーションを減らす設定（Windows の「アニメーション効果」をオフ など）が有効な場合、スカイラインのアニメーションは止まった状態で表示されます。
